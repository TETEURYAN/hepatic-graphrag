# Relatório RAG 01 - 07/05/2026

## 1. Introdução
Este relatório apresenta a análise quantitativa da distribuição de condições clínicas em um conjunto de dados de prontuários médicos. O objetivo principal é identificar a prevalência de doenças hepáticas e associadas, bem como analisar a ocorrência de casos multirrótulo (pacientes com múltiplas condições simultâneas).

## 2. Metodologia
A extração e validação dos dados foram realizadas por meio de consultas SQL aplicadas ao dataset de experimentação. As condições clínicas descritas nos prontuários foram agrupadas e normalizadas em categorias padronizadas (como Cirrose Hepática, Hipertensão Portal, Esquistossomose, entre outras) para permitir uma contagem assertiva.

*Nota: O caminho absoluto do dataset foi substituído por `<DATASET_PATH>` nas consultas abaixo para padronização.*

## 3. Consultas Realizadas e Resultados

### 3.1. Normalização e Frequência de Condições Específicas
Esta consulta foca exclusivamente nas doenças mapeadas e normalizadas. Ela contabiliza quantos prontuários apresentam 1, 2 ou 3 condições simultâneas dentre as doenças de interesse.

**Consulta SQL:**
```sql
WITH normalizado AS (
    SELECT
        prontuario_id,
        CASE
            -- CIRROSE
            WHEN UPPER(condicao) IN (
                'CIRROSE', 'CIRROSE HEPATICA', 'CIRROSE HEPÁTICA DESCOMPENSADA',
                'CIRROSE HEPÁTICA ALCOÓLICA', 'CIRROSE HEPÁTICA VIRAL C',
                'CIRROSE MICRONODULAR', 'CIRROSE DESCOMPENSADA', 'CIRROSE HEPÁTICA CRÔNICA'
            ) THEN 'CIRROSE HEPÁTICA'

            -- HIPERTENSÃO PORTAL
            WHEN UPPER(condicao) IN (
                'HIPERTENSAO PORTAL', 'HIPERTENSÃO PORTA', 'SINDROME DE HIPERTENSAO PORTAL',
                'SÍNDROME DE HIPERTENSÃO PORTAL', 'SÍNDROME DA HIPERTENSÃO PORTAL',
                'HIPERTENSÃO PORTAL NÃO CIRRÓTICA', 'HIPERTENSÃO PORTAL NÃO-CIRRÓTICA'
            ) THEN 'HIPERTENSÃO PORTAL'

            -- ESQUISTOSSOMOSE
            WHEN UPPER(condicao) IN (
                'EQUISTOSSOMOSE', 'ESQUISTOSSOMOSE HEPATOESPLENICA', 'ESQUISTOSSOMOSE HEPATOESPLÊNICA',
                'ESQUISTOSSOMOSE HEPATOESPLÊNICA (EHE)', 'ESQUISTOSSOMOSE MANSONI',
                'ESQUISTOSSOMOSE MANSÔNICA', 'EHE', 'EHE/HP'
            ) THEN 'ESQUISTOSSOMOSE'

            -- HEPATITE C
            WHEN UPPER(condicao) IN (
                'HEPATITE C (HCV)', 'HEPATITE C CRÔNICA', 'HEPATITE CRÔNICA VIRAL'
            ) THEN 'HEPATITE C'

            -- HEPATITE B
            WHEN UPPER(condicao) IN (
                'HEPATITE CRÔNICA B', 'HEPATITE B (HBV)', 'HEPATITE B CRONICA',
                'HEPATITE B INATIVA', 'HEPATITE B RESOLVIDA', 'HEPATITE CRÔNICA VIRAL B',
                'VÍRUS B (HEPATITE B)'
            ) THEN 'HEPATITE B'

            -- HDA
            WHEN UPPER(condicao) IN (
                'HDA', 'HEMORRAGIA DIGESTIVA ALTA', 'HDA (HEMORRAGIA DIGESTIVA ALTA)',
                'HDA VARICOSA', 'HEMORRAGIA DIGESTIVA ALTA VARICOSA', 'HEMORRAGIA VARICOSA'
            ) THEN 'HEMORRAGIA DIGESTIVA ALTA'

            -- PBE
            WHEN UPPER(condicao) IN (
                'PBE', 'PERITONITE BACTERIANA ESPONTÂNEA', 'PBE (PERITONITE BACTERIANA ESPONTÂNEA)',
                'PERITONITE BACTERIANA ESPONTANEA'
            ) THEN 'PERITONITE BACTERIANA ESPONTÂNEA'

            -- ESTEATOSE
            WHEN UPPER(condicao) IN (
                'ESTEATOSE', 'ESTEATOSE HEPATICA', 'ESTEATOSE HEPATICA DIFUSA',
                'DHGNA', 'NAFLD', 'MASLD', 'MASH', 'NASH',
                'DOENÇA HEPÁTICA GORDUROSA NÃO ALCOÓLICA', 'DOENÇA HEPÁTICA GORDUROSA NÃO ALCOÓLICA (DHGNA)',
                'DOENÇA HEPÁTICA ESTEATÓTICA METABÓLICA', 'DOENÇA HEPÁTICA ESTEATÓTICA METABÓLICA (MASH)',
                'ESTEATO-HEPATITE NÃO ALCOÓLICA', 'ESTEATO-HEPATITE NÃO ALCOÓLICA (NASH)',
                'ESTEATOHEPATITE', 'ESTEATOHEPATITE NÃO ALCOÓLICA',
                'DOENÇA HEPATICA ESTEATOSICA METABOLICA', 'DOENÇA HEPATICA ESTEATOTICA METABOLICA'
            ) THEN 'ESTEATOSE HEPÁTICA'

            ELSE NULL
        END AS condicao_normalizada
    FROM '<DATASET_PATH>'
),
por_prontuario AS (
    SELECT
        prontuario_id,
        COUNT(DISTINCT condicao_normalizada) AS qtd_condicoes
    FROM normalizado
    WHERE condicao_normalizada IS NOT NULL
    GROUP BY prontuario_id
)
SELECT
    qtd_condicoes,
    COUNT(*) AS quantidade_prontuarios
FROM por_prontuario
GROUP BY qtd_condicoes
ORDER BY qtd_condicoes;
```

**Resultados Obtidos:**
| Quantidade de Condições (`qtd_condicoes`) | Número de Prontuários (`quantidade_prontuarios`) |
|-------------------------------------------|--------------------------------------------------|
| 1                                         | 105                                              |
| 2                                         | 25                                               |
| 3                                         | 1                                                |

> **Interpretação:** A query identificou que 131 pacientes (105 + 25 + 1) possuem ao menos uma das doenças normalizadas de interesse. Dentre eles, 26 pacientes apresentam quadros de comorbidades (2 ou 3 condições simultâneas).


### 3.2. Relação de Condições Distintas e Contagem Global de Prontuários
Esta consulta busca todos os prontuários presentes na base de dados original, contabilizando a quantidade de condições distintas para cada um e as agrupando em formato de lista (string).

**Consulta SQL:**
```sql
WITH dados AS (
    SELECT *
    FROM '<DATASET_PATH>'
)
SELECT
    prontuario_id,
    COUNT(DISTINCT condicao) AS qtd_condicoes_distintas,
    STRING_AGG(DISTINCT condicao, ' | ' ORDER BY condicao) AS condicoes
FROM dados
GROUP BY prontuario_id
ORDER BY qtd_condicoes_distintas DESC, prontuario_id;
```

**Resultados Obtidos:**
- **Total de Prontuários Distintos:** 441
- *Nota: O agrupamento em string gera uma lista individual para cada um dos 441 prontuários detalhando suas condições específicas.*


### 3.3. Análise de Casos Multirrótulo (Comorbidades Globais)
Esta consulta calcula a proporção geral de prontuários multirrótulo na base de dados, ou seja, pacientes que possuem diagnóstico para mais de uma condição (independentemente de estarem nas normalizadas ou não).

**Consulta SQL:**
```sql
WITH dados AS (
    SELECT *
    FROM '<DATASET_PATH>'
),
multirrotulo AS (
    SELECT
        prontuario_id,
        COUNT(DISTINCT condicao) AS qtd_condicoes
    FROM dados
    GROUP BY prontuario_id
)
SELECT
    COUNT(*) AS total_prontuarios,
    SUM(CASE WHEN qtd_condicoes > 1 THEN 1 ELSE 0 END) AS prontuarios_multirrotulo,
    ROUND(
        100.0 * SUM(CASE WHEN qtd_condicoes > 1 THEN 1 ELSE 0 END) / COUNT(*),
        2
    ) AS percentual_multirrotulo
FROM multirrotulo;
```

**Resultados Obtidos:**
*A query retorna o universo total de 441 prontuários e a porcentagem exata de prontuários com `qtd_condicoes > 1` baseada em toda a variabilidade da base original.*

## 4. Conclusão
A análise quantitativa revela que, de um total de 441 prontuários distintos processados, 131 pertencem ao escopo direto das patologias hepáticas normalizadas (como Cirrose, Hipertensão Portal e Hepatites). A distribuição indica que a grande maioria destes pacientes (105) possui um diagnóstico único entre os mapeados, enquanto 26 prontuários evidenciam a presença de quadros associados.
